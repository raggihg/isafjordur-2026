# Logo notkun

Flest merki eru hlaðin beint úr opinberum/aðgengilegum logo-skrám:

- Framsókn: logo úr framsokn.is / Framer asset
- Sjálfstæðisflokkurinn: xd.is/wp-content/uploads/2025/10/xd2026.svg
- Viðreisn: Wikimedia Commons skrá með uppruna frá Viðreisn
- Samfylkingin: Wikimedia Commons skrá með merki Samfylkingarinnar
- Miðflokkurinn: staðbundið SVG merki er enn notað þar til bein logo-skrá úr media-kit er sett inn

Ef þú færð opinbera SVG/PNG skrá fyrir Miðflokkinn er nóg að setja hana í `public/logos/` og breyta `logo` slóðinni í `src/data/parties.js`.
